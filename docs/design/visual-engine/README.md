# Визуальный движок: печатный полевой бестиарий

Стиль B утверждён пользователем в `style-fit.html`. Исследование альтернатив и источники сохранены в `STYLE_RESEARCH.md`; исходные AI-макеты — в `in-context/`.

Реализованы три процедурных рига и растровый пак НейроФауны: 21 карта, 8 одиночных конечностей, 3 свойства, 3 стата, валюта, 6 типов клеток, 4 пустых состояния, две обложки. Сцены встроены в главную, примерку рынка, предложения, трек и пульт; обложка — во вход. Основные вкладки получили SVG-иконки. Другие темы пока процедурные.

## Сборка

Рисунки обрезаются по видимым границам, именованные крепления связывают голову, хвост и спинной модуль с корпусом. Конечности разделены на дальнюю и ближнюю стороны с перекрытием корпусом. Лапы сходятся к общей линии земли, крылья сохраняют свободную позу. Трубчатые торцы корпусов заменены цельным органическим силуэтом; хвост немного уходит под тело. Дополнительные кружки суставов удалены.

Фигура слегка покачивается целиком; конечности движутся вокруг креплений. Анимация отключается в token, reduced-motion и LOW. Для новых ассетов нужно соблюдать контракт anchors/contentBox/fragments; произвольные PNG без разметки не получают автоматического распознавания анатомии.

## Конвейер

Команды из корня:

```sh
npm run art:prompts -w @stem/art -- --pack neurofauna
npm run art:ingest -w @stem/art -- --pack neurofauna --only shark-body
npm run art:ingest -w @stem/art -- --pack neurofauna --only scorpion-claws --fragment limb
npm run art:validate -w @stem/art
npm run art:sheet -w @stem/art -- --pack neurofauna
```

`masters/<id>.png` и `masters/<id>-limb.png` — локальные исходники, исключённые из Git. Для воспроизведения сохранены prompts.jsonl и limb-prompts.jsonl. Ingest удаляет хромакей, нормализует размер, создаёт WebP и миниатюры с хешами, сохраняет крепления. Контактный лист в `packages/art/packs/neurofauna/contact-sheet.html` строится из тех же drawables, что приложение. Validate проверяет покрытие, альфу, размеры, вес и файлы фрагментов. Лимит пака — 3 MB.

## Проверки и границы этапа

Vitest: геометрия креплений, отражение anchors, дальние/ближние плоскости и общая опора, примерка без изменения оборудования; конвейер и процедурный fallback. Обязательные проверки: lint, typecheck, test, art:validate, build. Прирост JS/CSS и манифестов относительно dev остаётся в бюджете +25 KB gzip.

Системный reduced-motion, настоящий Telegram Android LOW и Slow 4G требуют аппаратной проверки. Отключение движения реализовано в CSS, LOW пока определяется по Android и числу ядер. Растровые паки остальных двух тем, полный набор UI-иконок, эффекты тиров и экспорт карточки остаются следующими этапами ТЗ.

Текущая проверка: 41 тест (19 art, 12 shared, 10 server), lint/typecheck/build/art:validate и production audit проходят. Пак НейроФауны — около 1.35 MiB. Главная проверена в настоящем приложении внутри viewport iframe шириной 375 px: [сборка и легенда](printed-assembly-375.png), [стык хвоста](printed-assembly-detail.png). Общая геометрия и загрузка подтверждены визуально; это не аппаратная эмуляция Telegram.
