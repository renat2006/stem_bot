# Сообщения бота и UX-тексты

Обращение на «вы», коротко, без эмодзи в шаблонах платформы (тема события может добавить свои). Все `{}` — переменные из конфигурации и события.

## Формат сообщения
```
<b>{Заголовок}</b>
{1–3 строки сути}
{опционально: список «Критерий · +N»}

{кто сделал}
[Кнопка 1] [Кнопка 2]   ← inline-кнопки, открывают Mini App на нужном экране (startapp-параметр)
```

## Шаблоны
| Событие | Заголовок | Тело | Кнопки |
|---|---|---|---|
| Начисление | Начисление · {День N / окно N} | +{sum} {валюта} команде «{team}»<br>{критерий} · +{n} (по строке на каждый, невыполненный — «· 0»)<br><br>Оценил(а) {admin}, {роль} | Открыть команду |
| Фаза открылась | {Фаза} открыт(а) | Тиры {I–III}, до {limit} покупок. Окно до {time}. | На рынок |
| Скоро закрытие | До закрытия {фазы} 10 минут | У вас {wallet} {валюта}, свободно покупок: {n}. | На рынок |
| Правила изменены | Правила изменены · версия {v} | {что поменялось}. {почему}. {что осталось прежним}. | Правила |
| Покупка | Покупка | «{card}» → {слот}<br>−{price} {валюта}, осталось {wallet}<br>«{old}» вытеснена<br>Купил капитан {cap} | Открыть команду |
| Отмена покупки | Покупка отменена | «{card}» вернулась на рынок, {price} {валюта} вернулись команде. | — |
| Предложение капитану | {member} предлагает покупку | «{card}» за {price} {валюта}<br>Шаг за ход: {a} → {b} | Купить за {price} · Не сейчас |
| Новый заказ | Новый заказ | «{order}»: при {стат} от {N} даёт +{reward} {валюта} и +{steps} шага. | Открыть |

## UX-тексты (из прототипа)
- Онбординг 1: «Учитесь — получайте {валюта}» / «После каждого блока админ отмечает 5 критериев учебной работы. Каждый даёт 2 {валюта}.»
- Онбординг 2: «Покупайте карты в слоты» / «В каждом слоте одна карта. Новая карта заменяет старую: склада нет, думайте, что вытесняете.»
- Онбординг 3: «Пороги дают шаги» / «Когда характеристика дотягивает до отмеченной клетки, вы получаете бонус к шагу. Кто дальше на треке, тот выше в рейтинге.»
- Не хватает валюты: «Не хватает N {валюта}» / «Следующее начисление за учёбу — в конце дня. Карты дешевле найдутся по фильтру «По карману».»
- Лимит: «Куплено 2 из 2» / «Следующие покупки — в следующей точке взаимодействия.»
- Карту купили раньше: «Карту купили раньше вас» / «Последнюю взяла «{team}». Завтра на рынке будут новые карты для слота «{слот}».»
- Нет прав: «Покупает капитан {cap}» / «Ему придёт карта с прогнозом шага, купить можно в одно касание.»
- Шаг падает: «Пунктирные блоки перестанут работать: {список}.»
- Пустой фильтр: «Под фильтр ничего нет» / «Попробуйте другой слот или снимите «По карману».» / [Показать все карты]
- Тосты: ««{card}» в сборке · −{price} {валюта}» [Отменить] · «Покупка отменена, {price} {валюта} вернулись» · «Предложение ушло капитану {cap}» · «Купить может только капитан».
