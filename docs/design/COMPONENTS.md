# Компоненты (кабинет участника)

Все размеры в px, цвета — токены из `tokens.css`. Компоненты получают только данные из конфигурации: никаких хардкод-строк «ДНК», «Существо» и т. п.

## Шаблон модуля
Каждый модуль механики или DLC регистрирует один и тот же набор частей:
```ts
interface ModuleUI {
  id: string;                         // 'slots' | 'track' | 'field' | 'orders' | 'market' | ...
  title: string;                      // «Сборка», «Ход», «Заказы»
  participantWidget?: React.FC<Ctx>;  // виджет на главной (C2)
  rules: (cfg) => RuleRow[];          // секция в «Правилах» и в справке «?»
  adminActions?: ...;                 // пульт (будет)
  boardRow?: ...;                     // табло (будет)
  constructorSection?: ...;           // конструктор (будет)
  enabledFromDay?: number;
}
```
Главная = список `participantWidget` включённых модулей в порядке из конфигурации. Каждый виджет обёрнут в **ModuleCard**:
- контейнер `sf`, рамка 1 `ln`, radius 16, overflow hidden;
- шапка: padding 8/8/8/14, нижняя граница `ln`; квадрат 8 × 8 radius 2 `ac` · title 14/600 · подзаголовок 12 `mu` (flex 1) · опциональный бейдж · кнопка «?» (44 × 36, внутри круг 22, рамка 1.5 `mu`, «?» 12/600);
- тело: padding 12/14/14.

## StatGlyph
Квадрат N × N (9–14 px), заливка `stat.color`, `clip-path` по форме:
- `tri` — `polygon(0 0,100% 50%,0 100%)` (Скорость)
- `up` — `polygon(50% 0,100% 100%,0 100%)` (Рост)
- `sq` — без clip, radius 2 (Сила)
- `hex` — `polygon(50% 0,100% 25%,100% 75%,50% 100%,0 75%,0 25%)` (Выживание / Устойчивость)
- `dia` — `polygon(50% 0,100% 50%,50% 100%,0 50%)` (Инновации)

Форма задаётся в теме события. У разных характеристик одной игры формы не повторяются, чтобы их можно было различить без цвета.

## Coin (валюта)
Круг N px (12 / 15 / 20), фон `--coin`, `box-shadow: inset 0 0 0 round(N/6)px var(--coin2)`. Всегда стоит справа от числа, gap 6–8.

## DeltaChip
inline-flex, gap 5, radius 6, фон `sf2`, моно 600; размер S — 11.5 px с padding 2/6, размер L — 13 px с padding 4/8. Содержимое: StatGlyph 9 + «+2» / «−2» (настоящий минус U+2212). Цвет текста `pos` или `neg`: знак всегда виден, информация не передаётся одним цветом.

## StatMeter (шкала с порогами)
Ряд клеток от −4 до +7 с разделителем на нуле (2 × 22, `mu`). Клетка — flex 1, высота 14, radius 2, gap 2. Над каждой клеткой место под метку высотой 12.
- Положительная клетка k заполнена, если value ≥ k (цвет характеристики). Отрицательная — если value ≤ k (`neg`). Пустая — `sf2`.
- Порог: `outline 1.5px ac`, offset 1, над клеткой «+N» моно 9/600 `ac`. Порог-опасность (поле событий): `warn`.
- Режим сравнения (before → after):
  - остаётся — сплошная заливка;
  - прибавится — `repeating-linear-gradient(135deg, col 0 2px, transparent 2px 4px)` и `inset 0 0 0 1px col`;
  - уйдёт — прозрачная клетка с `inset 0 0 0 1.5px neg`, opacity .8.
- Пороги в одной клетке суммируются (Сила ≥ 5: +1 порог и +2 свойство → «+3»).

## StepBlocks (шаг из блоков)
Ряд flex-блоков, gap 6, radius 10, padding 8/7. Сверху число 17–18 моно 600, снизу подпись 10.5 `mu` с глифом.
- «1 база» — всегда выполнен;
- порог: «+b» и «[глиф] от N»; свойство: ромб-контур `ac` и короткое имя;
- выполнен — фон `sf2`; не выполнен — прозрачный, рамка 1.5 dashed `ln`, «0», opacity .75;
- в сравнении: потерян — dashed `warn`, получен — solid `pos`;
- итог — «= N шаг» на `fg` / `bg`.

## ComponentCard (карта рынка)
Кнопка во всю ширину, `sf`, рамка `ln`, radius 16, padding 14, gap 10:
1. моно-подпись слота 10 px uppercase · справа TierBars + «III Продвинутая» моно 10.5;
2. имя 17/600 · справа цена 20 моно 600 + Coin 15;
3. DeltaChip L;
4. пунктирный разделитель; слева StockDots (точки 6 px: остаток — `fg`, продано — `ln`) и «2 из 3»; справа «шаг 4» + бейдж дельты (`warn` / `pos` / `sf2` с «=»);
5. примечание 12 `mu`: «Заменит «X»» / «В пустой слот» / «Продаёт команда «Орбита»» / «Раскупили · последнюю взяла «X»».

Состояния: обычное, раскупили (opacity .5), продаёт команда (DLC), выбрана (открыт sheet).

## TierBars
5 столбиков 3 × (5 + 2i), radius 1, gap 2. Заполнено `fg` по тиру, остальные `ln`. Тир дублируется римской цифрой и названием, поэтому не передаётся одним цветом.

## SlotTile (схема сборки)
Кнопка min-h 82, radius 12, padding 8/9. Заполненный слот: `sf`, рамка `ln`, тень `0 1px 2px rgba(0,0,0,.05)`. Пустой: прозрачный, 1.5 dashed `ac`, текст «пусто · N на рынке». Ячейка `core` — фон `fg`, текст `bg`, внутри объект и характеристики. Раскладка задаётся через `grid-template-areas` в теме:
- НейроФауна: `"front head back" "body core tail" ". special ."`
- Стартап: `"prod team mkt" "fin core tech"`

## PhaseRing + PhaseRail
Кольцо 66 px: `conic-gradient(var(--warn) pct%, var(--sf2) 0)`, внутренний круг inset 5 на `sf`. Полоса фаз: grid из 4 колонок, бары по 6 px, подпись 11 px. Фазы берутся из расписания точки.

## BuySlots
Квадраты 14 px radius 4 по числу лимита: свободная покупка — `ac`, использованная — `sf2` с `inset 1.5px ln`.

## MiniTrack
Клетки flex 1, высота 8 (своя — 12), gap 2, radius 2. Над клетками стек: точки соперников (5 px `mu`, максимум 2) и своя метка (9 px `ac` + кольцо 2 px `sf`). Прогноз хода — `inset 0 0 0 1.5px ac`.

## BottomSheet
Затемнение `--scrim`, лист `bg`, radius 20/20/0/0, padding 8/16/20, грабер 36 × 4 `ln`. max-h 94% для карты, 80% для справки. Закрывается тапом по затемнению или нативной «Назад».

## Toast with undo
Позиция absolute: left/right/bottom 12. Фон `fg`, текст `bg`, radius 12, тень `0 8px 24px rgba(0,0,0,.25)`. Слева точка 8 `ac2`, текст 13.5, кнопка «Отменить» 14/600 `ac2` высотой 44. Внизу полоса прогресса 3 px `ac2`, ширина = оставшееся / длительность.

## Tabs
Сегментированный контрол: 4 равные колонки, контейнер `sf2` radius 12 padding 3, кнопка 36 px radius 9, 13/500. Активная — `sf`, текст `fg`, тень; неактивная — `mu`.

## Native chrome (не рисовать в коде)
`BackButton`, `MainButton` (цвет = `ac`, текст = `acfg`, неактивная — `setParams({is_active:false, color: sf2, text_color: mu})`), `HapticFeedback`, `showConfirm` для необратимых действий.
