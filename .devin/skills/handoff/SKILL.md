Подготовь передачу контекста (Handoff) после выполнения задачи:

1. Проверь последние изменения через `git status` и `git log --oneline -5`.
2. Обнови `CHANGELOG.md` в корне репозитория (секция `[Unreleased]` -> `Added` / `Changed` / `Fixed`).
3. Актуализируй `docs/PROJECT_STATE.md`:
   - Перенеси выполненные пункты в таблицу `Done`.
   - Обнови список `Next Up` (что осталось сделать и какие есть блокеры/заметки).
4. Выдай краткую сводку для пользователя или следующего агента: что сделано, какие файлы затронуты и какой следующий шаг.
