# Визуальный движок: этап 1 и согласование стиля

Ветка `feat/visual-engine` от `dev`, 2026-10-14. Основание — [ТЗ](../VISUAL_ENGINE_BRIEF.md) §10, пункты 1–2.

## Реализовано

- `@stem/art`: Zod-контракт, три рига, три процедурных манифеста с палитрами, чистая композиция и имена видов. Все 43 текущие карты рисуются без AI-ассетов; неизвестные слоты размещаются на полке.
- `AssemblyStage`: hero/card/token, подложка, idle и установка/удаление деталей, примерка одного слота, доступное описание и отдельные кнопки пустых сокетов.
- `PartSticker`: процедурный SVG через image data URL; при наличии манифеста — растровый ассет, при ошибке — SVG. Для процедурных деталей пропорции вписываются в сокет; растровые используют contain.
- Интеграция: главная с текстовой легендой, миниатюры/примерка рынка, предложения, жетоны рейтинга, сцены пульта.
- Ленивая загрузка манифестов с кешем; preload установленных деталей hero. Docker учитывает новый workspace.

## Проверки

`npm run lint`, `npm run typecheck`, `npm test`, `npm run build`: успешно; 11 тестов art + 12 shared + 10 server. Прирост JS/CSS и ленивых манифестов — около 8 КБ gzip относительно ветки dev (лимит 25 КБ).

Риги проверены в браузере на ширине 375 px, светлой/тёмной теме: [светлая](rigs-light-375.jpg), [тёмная](rigs-dark-375.jpg). Проверено, что все изображения загрузились, ширина каждой сцены 347 px внутри контейнера 375 px. [Главная](neurofauna-dark-375.jpg) проверена в отдельной PGlite-БД, заполненной через API.

[Режим без анимаций](rigs-motion-off-375.jpg) проверен принудительным CSS-отключением в временном стенде. CSS-правило `prefers-reduced-motion` присутствует; системное переключение media preference, Slow 4G и настоящий Telegram Android LOW ещё не проверены. В установленном sdk-react v3 нет `useAndroidDeviceData`; до подключения доступного API используется консервативная эвристика Android + hardwareConcurrency ≤ 4. Эти ограничения не считать полной приёмкой производительности §6.
