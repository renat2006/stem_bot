## 3. Известные проблемы

**Безопасность (P0)** — подробно `docs/research/SECURITY.md`:
- Закрыто: команда и роль определяются по `user.id` из проверенного initData; анонимные мутации отклоняются.

**Игровое ядро**:
- Нет расчёта шага по треку, порогов клеток поля, эффектов перков, мутаций, откупов — только текст (`effectText`).
- Карты бесконечны (в оригинале уникальны), при замене слота старая карта исчезает.
- Покупка перка игнорирует день открытия.
- «Две механики» из требований не реализованы: два пресета — это одна механика с разными темами.
- Пресет НейроФауны: 16/78 карт, 3/15 перков, 6/16 клеток, расхождения в ценах и статах.

**Данные и инфраструктура**:
- Одно активное событие на инстанс; хаб WebSocket в памяти одного процесса (для нескольких инстансов — LISTEN/NOTIFY).
- Dev-зависимость `steiger` тянет уязвимую `braces` (DoS через glob, только dev-инструмент; прод-аудит чистый).
